VLA-RL — Residual Robot Learning

Residual TD3 control over a frozen SmolVLA policy in RoboCasa, starting with CloseFridge and validated integration checks.

Learning corrections to a base policy

VLA-RL investigates residual reinforcement learning for household manipulation. A frozen SmolVLA vision-language-action policy supplies the base actions, while a TD3 learner adds bounded arm corrections. The current implementation starts with the RoboCasa CloseFridge task.

Keeping the control interface explicit

The residual learner observes robot proprioception, pending base-policy actions, and the position within the action chunk. Images remain on the SmolVLA path. Base motion, control mode, and gripper commands remain unchanged while the residual wrapper constrains arm corrections.

Integration milestone and next steps

The current milestone includes live reward validation, zero-residual trajectory equivalence checks, and a short TD3 training smoke run. These checks establish integration behavior, not task competence or improved success rates. Evaluation under environmental changes and additional household tasks remain part of the broader study.
