PCB Defect Detection

Reference-guided PCB inspection using a lightweight tile gate and compact CNN, with an int8 export pipeline targeting ESP32-S3.

Inspecting boards within a microcontroller budget

This project targets bare-PCB inspection on the Seeed XIAO ESP32-S3 Sense. Aligned template and test images are divided into overlapping tiles. A lightweight first-stage gate filters matching regions so a compact multi-label CNN can focus on candidate defects.

Building the inspection pipeline

The implementation includes a DeepPCB tiling and labeling pipeline, classical-gate analysis, and a profiled student CNN. The export path connects PyTorch, ONNX, ESP-PPQ, and ESP-DL, with operator checks for the ESP32-S3 target.

Current scope

Benchmark firmware is written, but execution on the target hardware is pending. Model-training comparisons and the proposed defect-aware distillation study remain in development. The next milestones are hardware profiling and evaluation of the accuracy and compute trade-offs across the cascade.
