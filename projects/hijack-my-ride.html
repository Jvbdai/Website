hijackMyRide — Automotive AI Security

Prompt-injection research testbench connecting a Gemini assistant to Android Automotive emulator controls, with posted-notification tests, state verification, and restoration.

Testing the assistant trust boundary

hijackMyRide explores how untrusted text can influence an AI assistant that proposes vehicle-control commands. A host-side Python assistant connects Gemini to an Android Automotive OS emulator through an ADB translator. The translator checks supported controls and discovered limits before executing media-volume or HVAC-temperature commands.

From notification to verified state

An Android app posts test notifications inside the emulator. A host runner reads the posted text, supplies it to the model, and records proposed commands alongside observed before-and-after state. The live notification runner establishes restoration paths before testing and restores settings afterward.

Current scope

Offline tests and initial posted-notification trials exercise the pipeline. Broader repeated attack evaluation and an assistant running inside Android Automotive remain in development. The current work uses an emulator and a host-side assistant; it does not demonstrate attacks on a production vehicle or intake from a paired phone.

The source repository is private. This overview describes the research scope and current implementation.
